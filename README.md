# ht2sim

A toolkit for simulating and analysing Hitag2 protocol exchanges

![ht2sim](assets/ht2sim.jpg)

## Installation

Requires Python 3.10+.

```bash
git clone https://github.com/1577/ht2sim.git
cd ht2sim
python -m pip install -e .
```

## Usage

Launch the viewer:

```bash
python -m ht2sim.ui
```
